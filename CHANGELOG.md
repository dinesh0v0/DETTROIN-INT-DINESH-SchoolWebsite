# Changelog

All notable changes to this project are documented here.

## [1.1.0] — 2026-07-28

### Added
- Custom animated **404 NotFound** page with catch-all route
- `robots.txt` for SEO crawler control
- `CONTRIBUTING.md` with setup guide and commit conventions
- MIT `LICENSE` file
- Enhanced `/api/health` endpoint with uptime, memory, Node.js version info

### Changed
- `index.html` — added full SEO meta tags (description, keywords, Open Graph, theme-color)
- `README.md` — added mandatory intern submission section (name, email, live demo, tech stack, key improvements)

## [1.0.0] — 2026-07-27

### Added
- Full MERN backend with Express.js and MongoDB Atlas
- Admission form with email confirmation (Nodemailer)
- Job application with resume upload via MongoDB GridFS
- Fee payment recording
- Production deployment configs (Vercel + Render.com)
- Puppeteer script to auto-generate 4 themed PDF resources

### Changed
- Complete UI/UX redesign with TailwindCSS v4 + Framer Motion
- Premium dark-glass aesthetic with glassmorphism cards
- Responsive navigation with scroll-aware header
- Interactive 3D Dome Gallery component
- All pages rebuilt: Home, About, Academics, Admission, CoCurricular, Events, Gallery, JoinUs, Portal
